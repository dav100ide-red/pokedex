# Pokedex

Angular 21 single-page app that manages a trainer's Pokémon collection. Keep changes small, idiomatic
and buildable: `npx ng build` must pass with zero errors.

## Stack

- Angular 21.2 (standalone components, signals, zoneless, native control flow `@if` / `@for`),
  TypeScript 5.9 with `strict` and `strictTemplates`. Angular 21 docs for LLMs: https://v21.angular.dev/llms.txt
- PrimeNG 21.1.10, `@primeuix/themes` 2.0.3 and PrimeIcons 8.0.2 are installed but not configured yet
  (no `providePrimeNG`, no theme, no icon stylesheet, no component in use).
- `@angular/animations` is not installed and PrimeNG 21 does not need it.
- `package.json` is pinned: do not add, remove or upgrade dependencies.

## Layout

- `src/app/app.ts` (class `App`) renders `<router-outlet />`; `app.config.ts` holds the providers;
  `app.routes.ts` maps `''` to `Home`.
- `src/app/home/home.ts` (class `Home`) is the only page: it currently dumps the list with the `json`
  pipe and is the starting point of the UI.
- `src/app/data/pokemon.model.ts`: `Pokemon` = `id`, `name`, `types: string[]`, `level`,
  `capturedAt: Date`, `favorite: boolean`, `moves: string[]`, `imageUrl` (remote sprite URL).
- `src/app/data/pokemon.data.ts`: 50 in-memory records.
- `src/app/data/pokemon.service.ts`: `PokemonService` (`providedIn: 'root'`), signal-based state with
  `pokemons` (readonly signal), `getById`, `create`, `update`, `delete`. There is no HTTP backend.
- `src/styles.scss`: global styles, currently empty.

## Conventions

- Angular 21 CLI naming, no `Component` suffix: class `Home` in `home.ts`, template `home.html`,
  styles `home.scss`. Generate with `npx ng generate component <name>` (outputs `src/app/<name>/`).
- `inject()`, `input()` / `output()`, `computed()` and signals for state; reactive forms for editing.
- The official Angular best practices generated by `ng generate ai-config` are in `.claude/CLAUDE.md`.
- Commands: `npx ng build` (production build, budgets apply), `npx ng generate ...`.

## PrimeNG

Before writing any PrimeNG code, use the `primeng-21` skill: it has the v21 setup, theming, pitfalls and
a per-component reference with import paths and examples. For Angular questions, the Angular CLI MCP
server configured in `.mcp.json` provides `get_best_practices`, `search_documentation` and `find_examples`.
